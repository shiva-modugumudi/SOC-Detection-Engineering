# Detection Catalog

The following scenarios are an initial backlog. They are planned, not implemented or validated.

| Use case | Investigation focus | Status |
| --- | --- | --- |
| Password spraying | Failed sign-ins across multiple accounts from a common source | Planned |
| Repeated failures followed by a successful sign-in | Authentication sequence and account context | Planned |
| Suspicious PowerShell execution | Process command line, parent process, and related endpoint activity | Planned |
| Privileged group membership changes | Actor, affected account, approval, and subsequent activity | Planned |
| Cloud audit logging changes | Identity, API activity, affected resources, and expected maintenance | Planned |
| Unusual outbound data transfer | Destination, volume baseline, process, and business context | Planned |

Platform selection, telemetry, thresholds, and ATT&CK mappings will be documented when each use case is developed. No query files are supplied yet.

Follow the [use case guide](../docs/use-case-guide.md). Add a linked folder here when work starts, with an accurate status such as In development or Lab validated.
